# TSR (Terminate and Stay Resident) 演示

这个目录包含了 DOS 时代 TSR 程序的演示。

## 快速开始

```bash
./run_tsr_demo.sh
```

脚本会自动：
1. 检查并安装 DOSBox（通过 Homebrew）
2. 检查并安装 NASM 汇编器
3. 编译 TSR 程序
4. 启动 DOSBox 并挂载演示目录

## 手动安装（如果自动脚本失败）

```bash
# 安装 DOSBox
brew install dosbox

# 安装 NASM
brew install nasm

# 如果在 Apple Silicon Mac 上，需要先安装 Rosetta 2
softwareupdate --install-rosetta --agree-to-license

# 编译 TSR 程序
nasm -f bin -o CLOCK.COM clock_tsr.asm
nasm -f bin -o HOTKEY.COM hotkey_tsr.asm

# 启动 DOSBox
dosbox . -c "mount c ." -c "c:"
```

## 包含的 TSR 程序

### 1. CLOCK.COM - 时钟显示

- **功能**：在屏幕右上角显示实时时钟
- **原理**：钩住 INT 1Ch（用户定时器中断，由 INT 08h 每秒调用约 18.2 次）
- **使用**：运行 `CLOCK` 后，时钟自动显示

```

│ C:\>CLOCK                                                 12:34:56│
│ ===================================                              │
│   TSR Clock Demo - Now Installed!                                │
│ ===================================                              │
│                                                                  │
│ C:\>                                                             │
└─────────────────────────────────────────────────────────────────┘
```

### 2. HOTKEY.COM - 热键演示

- **功能**：按 F12 键显示弹出消息
- **原理**：钩住 INT 09h（键盘硬件中断）
- **使用**：运行 `HOTKEY` 后，按 F12 看效果


## TSR 工作原理

### 中断钩住机制

```
┌─────────────────────────────────────────────────────────────┐
│  正常情况                                                    │
│  键盘按下 → INT 09h → BIOS 键盘处理程序                     │
└─────────────────────────────────────────────────────────────┘

                    ↓ TSR 安装后

┌─────────────────────────────────────────────────────────────┐
│  TSR 钩住后                                                  │
│  键盘按下 → INT 09h → TSR 处理程序 → 原 BIOS 处理程序      │
│                       (检查热键)     (链式调用)              │
└─────────────────────────────────────────────────────────────┘
```

### 关键 DOS 中断

| 中断号 | 用途 | 调用频率 |
|--------|------|----------|
| INT 08h | 硬件定时器 | 18.2 次/秒 |
| INT 09h | 键盘硬件中断 | 每次按键 |
| INT 1Ch | 用户定时器钩子 | 18.2 次/秒 |
| INT 21h | DOS 服务 | 程序调用时 |

### 终止并驻留 (INT 21h, AH=31h)

```asm
mov ax, 3100h           ; AH=31h 终止并驻留
mov dx, 驻留段落数       ; 每段落 16 字节
int 21h
```

这个调用告诉 DOS："程序结束了，但不要释放我的内存！"
